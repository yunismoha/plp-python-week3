# PLP Python Week 3 - Grade Reporter & Bug Hunt

## Files

* `grade_reporter.py` - Uses loops and conditions to assign grades, count passes and failures, and calculate the average score.
* `bug_hunt.py` - Fixes three bugs in a while-loop program that calculates the sum of numbers from 1 to 5.

The hardest bug to find was the loop condition because the program could run without showing an error, but it stopped before adding 5. I knew something was wrong because the program printed a result other than the expected answer of 15.
